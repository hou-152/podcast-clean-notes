# 播客洗稿溯源 · 转写 → 笔记 → 概念 → 飞书

> Clean rough ASR transcripts into readable docs with auditable provenance.

直播、课程、会议的转写稿拿在手里，通常长这样：`发言人2 00:11`、「边干饭边摸索」、「踢美」、「火人感」…… 要拿它做笔记、喂给 AI、长期存档，都得先洗一遍。

手工洗稿有两怕：**改错**（把人家没说过的意思写进去）和**改丢**（不知道哪句被删、哪句被悄悄换掉）。大多数「AI 清洗」流程对这两件事都没有答案——洗完了，没有人能对账。

这套 skill 用两条铁律回应：**零删减**（只修错别字、断句、重复、口误；不改写、不压缩、不总结）和**不猜**（无法确证的内容原样保留、逐条标注）。并且给每一份清洗稿配上完整溯源件，让下游敢信。

## 流水线：四站接力，每站可单跑

```
00 原始转写（腾讯会议/通义听悟导出）
   ↓ ① transcript-clean-provenance  洗稿溯源
01 清洗稿 + 修订记录 + 待对清单 + 结论行
   ↓ ② note-taking-pro              三级笔记
02 三级笔记（骨架＋血肉）
   ↓ ③ concept-learning             概念提取
03 概念提取（逐字 context＋费曼解释＋分层架构图）
   ↓ ④ course-feishu-pack           打包交付
飞书文档 + 交付回执
```

站与站之间靠文件规约连接，不硬链——从任何一站单独接管都可以。

## 溯源长什么样

真实场次里，清洗稿的每一处改动都能对账：

| 原始转写 | 清洗稿 | 处理方式 |
|---|---|---|
| 边干饭边摸索 | 边干边摸索 | 听辨修正 |
| 跌位（两场同现） | 爹味 | 跨场收敛（词表有先例） |
| 反不进攻…… | 反不进攻（疑为「反复进攻」，存疑） | 不猜改 |
| 发言人   05:31（工具行） | （删除） | 结构清理 |

四条溯源链：

1. **改动对账**——每处修正进「修订记录」（原→改｜类别｜依据）；
2. **源冻结**——原始转写记录 SHA-256，处理全程只读；
3. **人名对号**——转写里的「发言人1/2/3」只是顺序编号不是身份；角色名逐个核对凭据，对不出的挂「待对清单」，人机合对后落版；
4. **跨场统一**——同一实体（人名/术语/写法）收敛进词表，一场定的，后面场次直接沿用。

## 四个 skill

| skill | 站 | 干什么 | 产物 |
|---|---|---|---|
| `transcript-clean-provenance` | ① | ASR 转写清洗成干净直播转写，附全套溯源件 | `01_*.md`＋修订记录＋待对清单＋结论行 |
| `note-taking-pro` | ② | 三级笔记：既能看见骨架，也能摸到血肉 | `02_*.md` |
| `concept-learning` | ③ | 概念基石提取＋费曼解释＋Mermaid 架构图 | `03_*.md` |
| `course-feishu-pack` | ④ | DOCX 打包＋飞书导入＋交付回执 | `*_飞书导入版.docx` |

## 三道质量门（可复跑）

```bash
python3 skills/transcript-clean-provenance/scripts/clean_lint.py  "<01 清洗稿>"
python3 skills/transcript-clean-provenance/scripts/trace_check.py "<00 原文>" "<01 清洗稿>"
python3 skills/transcript-clean-provenance/scripts/quote_gate.py  "<01 清洗稿>" "<02/03 产出>"
```

- **形状门** `clean_lint`——产物齐不齐、源哈希在不在、工具行清没清干净；
- **覆盖门** `trace_check`——零增删核对（字符清单覆盖＋体量比＋长块检测），丢内容立刻报警；
- **引文门** `quote_gate`——下游笔记的每一句引号逐字回溯清洗稿，伪引文直接拦截。

门不是装饰。实战中它们抓出过真错：头部哈希截断、漏洗一整块源文、拿省略号拼接两条原话当引文——都是「看起来没问题，机器一过就露馅」的类型。

## 设计原则

- **零删减**：清洗只修错别字、断句、重复、口误
- **不猜**：无法确证的内容原样保留并标注，一条不猜改
- **单源**：下游各站都以清洗稿为唯一输入，互不喂入
- **不硬链**：站与站靠文件规约连接，单跑、链式都行

## 实战验证

- 清洗模块经 10+ 场真实直播转写回测；四关压力测试全过（标准跑／三类拒绝／单跑守界／链式）
- 飞书交付端到端验证：转写 → 清洗 → 笔记 → 概念 → DOCX → 飞书 → 在线回读
- 词表随场次累积：人名、术语、常用写法的跨场收敛
